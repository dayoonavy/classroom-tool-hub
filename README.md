# 수업 도구 허브

교사가 만든 웹 도구를 한곳에서 여는 프론트엔드 전용 허브입니다. 첫 번째 도구는 초등 3~4학년용 곱셈·나눗셈 연습입니다.

## 실행

Node.js가 설치된 환경에서 이 폴더에서 실행합니다.

```sh
npm start
```

브라우저에서 <http://127.0.0.1:4173>을 여세요. 로컬 서버는 `127.0.0.1`에만 연결되며, 외부 패키지 설치나 인터넷 연결이 필요하지 않습니다. `dist/index.html`을 브라우저에서 직접 열어도 사용할 수 있습니다.

## 첫 번째 도구: 수학 문제 연습

- 한 회차는 곱셈 5문제와 나눗셈 5문제를 무작위 순서로 냅니다.
- 곱셈은 한 자리 수(2~9)끼리, 나눗셈은 두 자리 수를 한 자리 수로 나눕니다.
- 나눗셈은 나머지가 있을 수 있으며, 몫과 나머지를 각각 입력합니다.
- 문제마다 정오답을 알려주고, 오답이면 풀이를 표시합니다.
- 마지막에 10문제 점수를 보여주며, 다시 풀거나 허브로 돌아갈 수 있습니다.
- 기본 수학 연습은 계정 없이 사용할 수 있으며, 이 연습의 이름·답안·점수는 저장하지 않습니다.

## 허브 관리

프로그램은 카드형 바로가기로 표시합니다. GitHub Pages로 허브와 PDF 글자 수 세기를 배포하고, 하루 기록은 Firebase Hosting, 수학 게임은 Vercel에 연결합니다.

디자인은 제공된 `DESIGN.md`의 밝은 배경, 넓은 여백, 간결한 글자, 파란색 포인트와 그림자 없는 28px 카드 곡률을 웹 도구 허브에 맞게 적용했습니다.

## 수학 게임 포털

`dist/games/index.html`에 연산·수열·분수 게임을 추가했습니다. 허브의 수학 게임 포털 카드에서 열 수 있습니다. 각 게임은 3단계 난이도와 10문제이며, Supabase 아이디/비밀번호 계정으로 로그인하면 사용자별 학습 기록을 저장합니다.

### 로그인 및 기록

수학 게임은 Supabase Auth 아이디/비밀번호 계정과 사용자별 RLS 보호가 적용된 `game_records` 테이블을 사용합니다. 비밀번호를 분실하면 담당 교사에게 문의하도록 안내합니다. GitHub Pages 배포 워크플로는 `.github/workflows/deploy-pages.yml`에 있습니다.
